## Intuition

As an AI project grows, you cannot cram thousands of lines of code into a single flat script. You need to:

- Package repeated logic into reusable **functions**: a data loader function, a loss calculation function, a text normalization function.
- Ensure that modifying variables inside a function does not accidentally corrupt data elsewhere in your program.
- Read training datasets from disk and save model weights or training logs after each epoch.

Every production AI system—from data preprocessing pipelines to checkpoint loaders—relies on three pillars: **functions for modular logic**, **strings for text representation**, and **file I/O for persistent storage**.

## Theory

### Function Structure and Type Hints

A standard Python function starts with the `def` keyword, a function name, a parameter list, and a `return` statement:

```python
def compute_loss(y_true: float, y_pred: float) -> float:
    """Compute the squared error between true and predicted values."""
    return (y_true - y_pred) ** 2
```

- **Type hints:** Help human readers and static type checkers (such as MyPy) catch type mismatches early without slowing down runtime execution.
- **Positional and keyword arguments:** You can call `compute_loss(1.0, 0.8)` positionally or explicitly by name: `compute_loss(y_pred=0.8, y_true=1.0)`.
- **Flexible arguments `*args` and `**kwargs`:**
  - `*args`: Packs extra positional arguments into a `tuple`.
  - `**kwargs`: Packs extra keyword arguments into a `dict`.

### Variable Scope (LEGB Rule)

When you reference a variable name inside a function, Python looks it up in **LEGB** order:

1. **L (Local):** Variables defined inside the current function.
2. **E (Enclosing):** Variables in the outer enclosing function (for nested functions).
3. **G (Global):** Variables defined at the top level of the module/file.
4. **B (Built-in):** Python's built-in functions and names (`print`, `len`, `range`).

To reassign a global variable from inside a function, you would have to declare `global`. However, in production AI code, mutating global variables is strongly discouraged because it makes state hard to track and introduces hidden side effects.

### String Processing

Strings (`str`) in Python are **immutable**. Once a string is created in memory, you cannot modify individual characters in place (`s[0] = 'H'` raises a `TypeError`).

Essential string normalization methods for NLP:
- `.strip()`: Removes leading and trailing whitespace.
- `.lower()`: Converts all characters to lowercase.
- `.replace(old, new)`: Replaces occurrences of a substring.
- `.split(sep)`: Splits a string into a list of tokens.
- `sep.join(list_of_strings)`: Joins a list of strings into a single string using `sep` as the delimiter.

### Safe File I/O with Context Managers

When a program opens a file, the operating system allocates a file descriptor. If your code opens many files without closing them, the OS will eventually run out of file handles or leave data unwritten in memory buffers.

The idiomatic way to work with files in Python is the `with` statement:

```python
with open("data.txt", mode="r", encoding="utf-8") as f:
    content = f.read()
# As soon as execution leaves the with block, the file is closed automatically!
```

Common file modes (`mode`):
- `"r"`: Read text (raises `FileNotFoundError` if the file does not exist).
- `"w"`: Write text (overwrites existing contents or creates a new file).
- `"a"`: Append text to the end of the file.

**Structured storage with JSON:** Python's standard `json` module converts seamlessly between Python objects (`dict`, `list`) and JSON text files via two main functions:
- `json.dump(obj, file)`: Serializes a Python object directly to a file.
- `json.load(file)`: Reads and parses a JSON file back into a Python object.

## Illustration

Python's LEGB variable lookup hierarchy:

```text
        [ B - Built-in Scope ] (Built-in names: print, len, sum...)
                  ▲
        [ G - Global Scope ] (Module-level variables)
                  ▲
        [ E - Enclosing Scope ] (Outer enclosing function)
                  ▲
        [ L - Local Scope ] (Inside the currently executing function)
```

Safe file lifecycle with a `with` Context Manager:

```text
[ open("file.json", "w") ] ──► Calls __enter__(): Opens file, allocates File Descriptor
           │
           ▼
[ Execute code block ] ──► Writes data to disk, runs processing logic...
           │
           ├─► (Completes normally) ─────┐
           │                             ├──► Calls __exit__(): CLOSES FILE AUTOMATICALLY!
           └─► (Raises an Exception) ────┘
```

## Common pitfalls

:::caution[The Mutable Default Argument Trap]
When you write `def train_step(data, history=[]):`, the empty list `[]` is created **only once** when Python first loads the function definition. If you call the function multiple times without passing `history`, every call mutates that same shared list! Always use `None` as the default instead: `def train_step(data, history=None): if history is None: history = []`.
:::

:::caution[Forgetting `encoding="utf-8"` when opening files]
On Windows, `open()` may default to a legacy locale encoding (such as CP1252), causing `UnicodeDecodeError` or garbled characters when reading multilingual text datasets. Always pass `encoding="utf-8"` explicitly whenever opening text files.
:::

:::caution[Concatenating strings with `+` inside large loops]
Because strings are immutable, writing `text += token` in a loop allocates a new string and copies the entire existing string on every iteration. Across tens of thousands of tokens, runtime balloons quadratically. Append tokens to a `list` first and call `"".join(tokens)` once at the end.
:::

## Summary and further reading

**Key takeaways:**

- Functions encapsulate reusable logic; type hints clarify expected types and help catch bugs early.
- Avoid mutable default arguments: always default to `None` for parameters that hold a `list` or `dict`.
- The LEGB rule governs how Python resolves variable names from local to built-in scopes.
- Strings are immutable: every string transformation creates a new object, so use `.join()` when combining many substrings.
- Always use `with open(...)` and `encoding="utf-8"` to guarantee safe resource cleanup and consistent text encoding.
