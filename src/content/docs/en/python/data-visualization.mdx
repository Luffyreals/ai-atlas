## Intuition

In the famous story of *Anscombe's quartet*, four distinct datasets share the exact same mean, variance, correlation coefficient, and linear regression line. Yet the moment you plot them on a graph:
- One dataset follows a clean linear trend with mild noise.
- A second dataset forms a smooth parabolic curve.
- Another dataset is skewed dramatically by a single extreme outlier!

If you rely solely on summary statistics, your data can easily fool you. **Data Visualization** acts as your microscope to:
1. Catch anomalies, corrupted values, and outliers before feeding data into a neural network.
2. Monitor the "heartbeat" of your machine learning model throughout training via loss curves.

## Theory

### Matplotlib's Object-Oriented Architecture

Matplotlib offers two interfaces: a stateful MATLAB-style interface (`plt.plot(...)`) and an explicit **Object-Oriented (OO) API**. In professional AI codebases, the object-oriented approach is the gold standard:

```python
fig, ax = plt.subplots(figsize=(8, 5))
```

- **`Figure` (Canvas):** The top-level container holding the entire graphic. It controls overall figure dimensions, background color, figure-wide titles, and all child subplots.
- **`Axes` (Coordinate System):** The actual plotting area inside a Figure. Each `Axes` owns an X-axis, a Y-axis, ticks, axis labels, a grid, and the plotted data artists. A single `Figure` can hold multiple `Axes` arranged in a grid (for instance, an input image on the left and a class probability bar chart on the right).

### Essential Plots in Machine Learning

#### 1. Line Plot: Monitoring Training Progress

A line plot connects sequential data points across time or training epochs.
- X-axis: Epoch number (or gradient update step).
- Y-axis: Loss value or evaluation metric (accuracy, F1-score).
- AI use case: Monitoring convergence speed and spotting the exact epoch where validation loss diverges from training loss (overfitting).

#### 2. Scatter Plot: Exploring Feature Space

A scatter plot renders each data sample as a point on a 2D plane $(x_1, x_2)$:
- Reveals linear or nonlinear relationships between two features.
- Highlights natural clusters in unsupervised learning.
- Visualizes decision boundaries separating classification classes.

#### 3. Histogram and Kernel Density Estimation (KDE): Inspecting Distributions

- **Histogram:** Divides a continuous range into intervals (**bins**) and counts how many samples fall into each bin.
- **KDE (Kernel Density Estimation):** Smooths the histogram into a continuous probability density curve.
- AI use case: Checking whether a feature follows a bell-shaped Gaussian distribution or is heavily skewed. Many algorithms (such as Linear Regression and PCA) perform best when input features are roughly symmetric and unimodal.

#### 4. Box Plot: Detecting Outliers

A box plot summarizes a distribution through five key percentiles:
- Median ($Q_2$): The line dividing the box.
- Interquartile box: Spans the middle 50% of the data from $Q_1$ (25th percentile) to $Q_3$ (75th percentile), with width $\text{IQR} = Q_3 - Q_1$.
- Whiskers: Extend to the most extreme data points within $[Q_1 - 1.5 \times \text{IQR}, Q_3 + 1.5 \times \text{IQR}]$.
- Individual points plotted beyond the whiskers are **outliers** that warrant closer inspection.

#### 5. Correlation Heatmap

Built on top of Matplotlib, **Seaborn** provides the `sns.heatmap()` function for visualizing matrices:
- Compute pairwise correlations across all columns with `corr = df.corr()`.
- Render values as color-coded cells: warm colors indicate strong positive correlation, cool colors indicate strong negative correlation.
- Quickly spot **multicollinearity** so you can drop redundant features.

## Illustration

The hierarchical relationship between `Figure` and `Axes` in Matplotlib:

```text
┌──────────────────────────────────────────────────────────────┐
│  Figure (Top-level outer canvas)                             │
│                                                              │
│  ┌────────────────────────────┐  ┌─────────────────────────┐ │
│  │ Axes 1 (Train Loss plot)   │  │ Axes 2 (Val Loss plot)  │ │
│  │  ▲ Loss                    │  │  ▲ Loss                 │ │
│  │  │ ╲                       │  │  │ ╲    ╱               │ │
│  │  │  ╲                      │  │  │  ╲──╱                │ │
│  │  └────────► Epoch          │  │  └────────► Epoch       │ │
│  └────────────────────────────┘  └─────────────────────────┘ │
└──────────────────────────────────────────────────────────────┘
```

Diagnosing overfitting from training and validation loss curves:

```text
 Loss
  ▲
  │   Train Loss keeps dropping ──► Model memorizes training set
  │╲
  │ ╲       Early Stopping point
  │  ╲            ▼
  │   ╲───────────┬───────────────
  │    ╲          │   ╱
  │     ╲─────────┴──╱  ◄─── Val Loss rebounds upward (Overfitting!)
  └──────────────────────────────► Epoch
```

## Common pitfalls

:::caution[Mixing stateful `plt.*` calls with the Object-Oriented `ax.*` API]
Mixing `plt.plot()` and `ax.plot()` in the same script makes subplot customization confusing and error-prone when working with multi-panel figures. Always initialize with `fig, ax = plt.subplots()` and call methods directly on `ax` (`ax.set_title()`, `ax.set_xlabel()`).
:::

:::caution[Forgetting to close figures in loops and leaking RAM]
When generating hundreds of plots inside an evaluation or image-saving loop, Matplotlib keeps every open figure object in memory until explicitly closed. Always call `plt.close(fig)` after saving a figure to disk to prevent out-of-memory crashes.
:::

:::caution[Ignoring wildly different axis scales]
When plotting 2D feature scatter plots or gradient descent contour maps, if one axis spans `0` to `1` while the other spans `0` to `10,000`, the visual geometry becomes severely distorted unless you standardize features or set equal aspect ratios (`ax.set_aspect('equal')`).
:::

## Summary and further reading

**Key takeaways:**

- Exploratory Data Analysis (EDA) is mandatory before training any machine learning model; visualization uncovers structural patterns that summary statistics miss.
- Use Matplotlib's object-oriented API: `Figure` is the outer canvas and `Axes` is the coordinate system holding a specific subplot.
- Line plots track loss curves and provide early warning of overfitting or underfitting.
- Box plots and scatter plots are indispensable for spotting outliers and understanding feature space geometry.
