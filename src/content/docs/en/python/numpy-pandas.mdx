## Intuition

Why can't we train neural networks using standard Python `list` objects?

Consider a simple task: multiplying a $1000 \times 1000$ image matrix by a weight matrix.
- With nested `for` loops in pure Python, the interpreter has to execute 1 billion multiply-add operations. On every single step, Python checks data types, dereferences pointers, and allocates new boxed objects—taking tens of seconds.
- With **NumPy**, all 1 million numbers sit side by side as raw binary bytes in a contiguous block of RAM. The CPU can process chunks of numbers simultaneously in a single hardware instruction (**SIMD** – Single Instruction, Multiple Data), finishing the calculation in milliseconds!

**NumPy** is the mathematical engine underneath virtually every machine learning and deep learning library, while **Pandas** is your data workbench for cleaning, transforming, and exploring real-world datasets before feeding them into a model.

## Theory

### NumPy and the N-Dimensional Array (`ndarray`)

The `ndarray` (N-dimensional array) is NumPy's core data structure:
- Every element in an array must share the **same data type** (homogeneous, such as `float32` or `int64`).
- The dimensions of the array are stored in `.shape` (a tuple of integers).
- The element data type is stored in `.dtype`.

#### Vectorization: Loop-Free Array Computing

**Vectorization** means expressing operations across entire arrays at once instead of iterating element by element in a Python `for` loop.

Instead of writing:

```python
# Slow (Python for-loop):
c = [a[i] * b[i] for i in range(len(a))]
```

You write:

```python
# Fast vectorized computation (NumPy C-speed):
c = a * b
```

#### Broadcasting

Broadcasting allows NumPy to perform arithmetic between arrays of different shapes without making wasteful copies in memory.

**Broadcasting rules:** When aligning two arrays, NumPy compares their dimension sizes from **right to left**:
1. The two dimensions are equal: compatible.
2. One of the dimensions is 1: that dimension is virtually stretched to match the other.
3. The dimensions differ and neither is 1: NumPy raises `ValueError: operands could not be broadcast together`.

For example, adding a vector of shape $(3,)$ to a matrix of shape $(4, 3)$ automatically views the vector as $(1, 3)$ and broadcasts it across all 4 rows to produce a $(4, 3)$ result.

### Pandas: Tabular Data Analysis and Manipulation

Pandas provides two primary data structures:
- **Series:** A 1D labeled array with an index.
- **DataFrame:** A 2D table of rows and columns (similar to an Excel spreadsheet or SQL table).

#### Indexing Data: `.loc` vs. `.iloc`

To avoid ambiguity, Pandas separates indexing into two explicit accessors:
- **`df.loc[...]`:** **Label-based** indexing. You pass row index labels and column names.
- **`df.iloc[...]`:** **Integer position-based** indexing from `0` to `n - 1`.

```python
# Select the row with index label "HN" and column "price":
val = df.loc["HN", "price"]

# Select the 0th row and 2nd column by physical integer position:
val = df.iloc[0, 2]
```

#### Handling Missing Data

Real-world datasets almost always contain missing values (`NaN` – Not a Number, or `None`). Essential methods include:
- `df.isna().sum()`: Count missing values in each column.
- `df.dropna()`: Drop rows or columns containing missing values.
- `df.fillna(value)`: Impute missing entries with a replacement value (such as the column `.mean()` or `.median()`).

#### Grouping and Aggregation with `.groupby()`

Pandas implements the **Split-Apply-Combine** pattern via `.groupby()`:

```python
# Group by apartment type and compute average area
df.groupby("type")["area"].mean()
```

You can also chain `.agg()` to compute multiple summary statistics across different columns in a single call.

## Illustration

How NumPy broadcasting stretches compatible array shapes:

```text
Matrix A (3 × 3):                Vector B (1 × 3):
┌───┬───┬───┐                    ┌───┬───┬───┐
│ 1 │ 2 │ 3 │                    │ 10│ 20│ 30│
├───┼───┼───┤                    └───┴───┴───┘
│ 4 │ 5 │ 6 │         +                │ (Virtually broadcast across 3 rows)
├───┼───┼───┤                          ▼
│ 7 │ 8 │ 9 │                    ┌───┬───┬───┐
└───┴───┴───┘                    │ 10│ 20│ 30│
                                 ├───┼───┼───┤
                                 │ 10│ 20│ 30│
                                 ├───┼───┼───┤
                                 │ 10│ 20│ 30│
                                 └───┴───┴───┘
```

The Split-Apply-Combine workflow in Pandas `.groupby()`:

```text
[ Raw Data ] ──► SPLIT (Partition rows by category: A, B)
                    ├── Group A ──► APPLY: Compute mean ──┐
                    └── Group B ──► APPLY: Compute mean ──┴──► COMBINE: Merge into summary table
```

## Common pitfalls

:::caution[Shape mismatch errors in matrix multiplication]
The `@` operator performs linear algebra matrix multiplication: the number of columns in the left matrix must equal the number of rows in the right matrix ($A_{(m \times k)} @ B_{(k \times n)} \to C_{(m \times n)}$). Confusing matrix multiplication `@` with element-wise multiplication `*` when dimensions do not align raises `ValueError: matmul: Input operand 1 has a mismatch in its core dimension 0`.
:::

:::caution[Iterating over DataFrame rows with a `for` loop]
Writing `for index, row in df.iterrows():` to compute column values row by row slows execution down by orders of magnitude. Always use vectorized Pandas/NumPy expressions such as `df["col_c"] = df["col_a"] + df["col_b"]`.
:::

:::caution[Triggering `SettingWithCopyWarning`]
When you modify a filtered subset of a DataFrame (e.g., `sub_df["price"] = 10`), Pandas cannot always tell whether you intend to modify a temporary view or the original table. Call `.copy()` explicitly if you want an independent DataFrame (`sub_df = df[cond].copy()`), or use `df.loc[cond, "price"] = 10` to update the original DataFrame directly.
:::

## Summary and further reading

**Key takeaways:**

- NumPy's `ndarray` stores homogeneous data in contiguous C memory blocks, achieving massive speedups through CPU cache locality and SIMD instructions.
- Vectorization replaces manual Python loops with concise, C-speed array expressions.
- Broadcasting stretches compatible array dimensions automatically without copying data in memory.
- Pandas provides `DataFrame` and `Series` for expressive tabular manipulation using `.loc`, `.iloc`, `.fillna()`, and `.groupby()`.
