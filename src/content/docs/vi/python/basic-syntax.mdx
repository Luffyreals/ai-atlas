## Lý thuyết

### Biến và Cơ chế Tham chiếu Đối tượng

Trong nhiều ngôn ngữ lập trình như C++ hay Java, một biến giống như một chiếc hộp chứa giá trị: gán giá trị nghĩa là đổ dữ liệu vào hộp. Nhưng trong Python:

> **Biến là một chiếc nhãn (name tag) dán vào một đối tượng cụ thể trong bộ nhớ RAM.**

Khi bạn viết `x = 10`, Python tạo ra một đối tượng số nguyên có giá trị `10` trong vùng nhớ, sau đó gán nhãn `x` trỏ tới đối tượng đó.

- Hàm `type(x)`: Trả về kiểu dữ liệu của đối tượng mà biến đang trỏ tới.
- Hàm `id(x)`: Trả về mã số định danh duy nhất (tương ứng với địa chỉ ô nhớ) của đối tượng.

```python
a = [1, 2, 3]
b = a  # b dán nhãn vào cùng danh sách mà a đang trỏ tới!
b.append(4)
# Lúc này a cũng trở thành [1, 2, 3, 4]
```

### Các Kiểu Dữ Liệu Nguyên Thủy

1. **Số nguyên (`int`):** Có độ chính xác tùy ý, không bị giới hạn tràn số như kiểu 32-bit hay 64-bit trong các ngôn ngữ khác.
2. **Số thực (`float`):** Tuân theo chuẩn IEEE 754 (độ chính xác kép 64-bit). Cần đặc biệt chú ý sai số xấp xỉ nhị phân: không bao giờ dùng `==` để so sánh hai số thực trong các thuật toán máy học; hãy dùng khoảng sai số epsilon hoặc `math.isclose(a, b)`.
3. **Giá trị logic (`bool`):** Chỉ mang một trong hai giá trị `True` hoặc `False`.
4. **Chuỗi văn bản (`str`):** Chuỗi ký tự Unicode bất biến (immutable). Dùng f-string (`f"Giá trị: {val:.2f}"`) để định dạng văn bản trực quan.

### Toán Tử Logic và Đánh Giá Ngắn Mạch

Python hỗ trợ ba toán tử logic: `and`, `or`, và `not`.

Quy tắc chuyển đổi sang chân lý (Truthy và Falsy): Trong ngữ cảnh điều kiện, các giá trị sau đây được coi là `False`:
- Số `0`, `0.0`
- Đối tượng rỗng: `""`, `[]`, `()`, `{}`, `set()`
- Hằng số `None` và `False`

Mọi giá trị khác đều được coi là `True`.

**Cơ chế Đánh giá Ngắn mạch (Short-circuit Evaluation):**
- Với `A or B`: Nếu `A` đúng, Python kết luận ngay kết quả là `True` mà không bao giờ tính biểu thức `B`.
- Với `A and B`: Nếu `A` sai, Python kết luận ngay kết quả là `False` mà bỏ qua `B`.

Đặc tính này rất hữu ích khi bạn cần kiểm tra điều kiện an toàn trước khi truy xuất dữ liệu:

```python
if data is not None and len(data) > 0:
    process(data)
```

### Cấu Trúc Điều Kiển: Điều Kiện và Vòng Lặp

Python dùng khoảng thụt lề (thường là 4 dấu cách) để xác định khối lệnh (block scope), thay vì dùng cặp dấu ngoặc nhọn `{}`:

1. **Rẽ nhánh `if` – `elif` – `else`:** Kiểm tra tuần tự từ trên xuống dưới, chỉ thực thi khối lệnh đầu tiên có điều kiện thỏa mãn.
2. **Vòng lặp `for`:** Lặp qua từng phần tử của một đối tượng có thể lặp (iterable) như dãy số, danh sách:
   - `range(stop)` hoặc `range(start, stop, step)`: Sinh dãy chỉ số.
   - `enumerate(iterable)`: Trả về cặp `(chỉ_số, phần_tử)`, rất phổ biến khi cần đếm số bước huấn luyện (step/epoch).
   - `zip(list1, list2)`: Ghép từng cặp phần tử tương ứng của hai danh sách cùng lúc.
3. **Vòng lặp `while`:** Tiếp tục lặp chừng nào điều kiện còn đúng. Thường dùng khi thuật toán tối ưu chưa đạt ngưỡng hội tụ.
4. **`break` và `continue`:**
   - `break`: Thoát khỏi vòng lặp ngay lập tức.
   - `continue`: Bỏ qua các câu lệnh còn lại của vòng lặp hiện tại để chuyển sang vòng lặp kế tiếp.

## Minh họa

Bảng dưới đây tóm tắt các phép toán số học và toán tử logic cốt lõi trong Python:

| Toán tử | Cú pháp | Ý nghĩa trong tính toán AI | Ví dụ |
| :--- | :--- | :--- | :--- |
| **Chia thực** | `/` | Chia trả về kết quả số thực `float` | `7 / 2 -> 3.5` |
| **Chia nguyên** | `//` | Chia lấy phần sàn, thường dùng chia batch | `7 // 2 -> 3` |
| **Chia dư** | `%` | Lấy phần dư, dùng để in log mỗi $N$ epoch | `step % 10 == 0` |
| **Lũy thừa** | `**` | Tính mũ (bình phương sai số trong loss) | `error ** 2` |
| **So sánh giá trị** | `==`, `!=` | Kiểm tra độ tương đương nội dung | `y_pred == y_true` |
| **So sánh vùng nhớ** | `is`, `is not` | Kiểm tra đối tượng duy nhất (thường dùng cho `None`) | `model is None` |
| **Toán tử logic** | `and`, `or`, `not` | Kết hợp nhiều điều kiện lọc mẫu dữ liệu | `score > 0.8 and not flagged` |

Quy trình vòng lặp tối ưu hóa hội tụ cơ bản trong máy học:

```text
[ Khởi tạo trọng số w ]
        │
        ▼
   ┌──► [ Tính gradient của hàm mất mát: grad = 2 * w ]
   │    │
   │    ▼
   │  { Kiểm tra: abs(grad) < tolerance? }
   │    ├─► ĐÚNG ──► [ Đã hội tụ! Thoát vòng lặp: break ] ──► (Kết thúc)
   │    │
   │    └─► SAI
   │         │
   │         ▼
   │       [ Cập nhật trọng số: w = w - lr * grad ]
   └─────────┘ (Lặp lại cho epoch tiếp theo)
```

## Lỗi hay gặp

:::caution[Nhầm lẫn giữa toán tử `==` và `is`]
Toán tử `==` dùng để so sánh **giá trị** của hai biến có tương đương nhau hay không. Toán tử `is` dùng để so sánh **định danh** xem hai biến có cùng trỏ tới một địa chỉ ô nhớ trong RAM hay không. Khi kiểm tra một biến có rỗng hay không, quy chuẩn PEP 8 khuyên bạn luôn viết `if x is None:` chứ không dùng `if x == None:`.
:::

:::caution[So sánh số thực bằng toán tử `==`]
Do sai số biểu diễn nhị phân của chuẩn IEEE 754, phép so sánh `0.1 + 0.2 == 0.3` trả về `False`. Trong các thuật toán huấn luyện học máy, khi muốn so sánh sự hội tụ của hàm mất mát giữa các epoch, luôn sử dụng khoảng dung sai cho phép: `abs(loss_new - loss_old) < 1e-5` hoặc dùng hàm `math.isclose()`.
:::

:::caution[Bẫy lặp vô hạn và lỗi lệch 1 (Off-by-one error)]
Trong vòng lặp `while`, nếu bạn quên cập nhật biến điều kiện bên trong thân vòng lặp, chương trình sẽ rơi vào trạng thái treo vô tận (infinite loop). Ngoài ra, hàm `range(start, stop)` chỉ chạy tới `stop - 1`. Viết `range(1, 5)` sẽ chỉ tạo ra các số `1, 2, 3, 4` chứ không bao gồm số `5`.
:::
