  - Quiz đặt trong frontmatter, có schema zod. KaTeX render lúc build. Island 3,5 KB.
  - Build báo lỗi nếu chuỗi quiz có ký tự điều khiển (bẫy `"\frac"` trong YAML).
- **M1-4, lõi `PythonRunner`** (Pyodide 314.0.7 từ jsDelivr, Web Worker):
  - Có hàng đợi. Nút Dừng chỉ dừng ô của mình, các ô đang chờ chạy trên worker mới.
  - Output tối đa 100.000 ký tự. Gợi ý bấm Dừng sau 10 giây.
  - Code lỗi vẫn trả về hình vẽ trước lúc lỗi (tối đa 10 hình). Số dòng lỗi khớp code người dùng.
  - Lệch spec: stdout dùng `write` thay `batched`, vì `batched` làm mất chữ in cuối chương trình khi không có `\n`.
- **M1-5, giao diện PythonRunner:** 5 file code mẫu vi/en trong `src/code/dev/`, sửa `docs/lesson-template.mdx`. Rủi ro 6 đã xảy ra (đặt `<Code>` làm children của island thì mất CSS của Expressive Code), đã chuyển `<Code>` ra ngoài island.
- **M1-6/7/8:** test jsdom cho `QuizIsland` và `PythonRunnerIsland`, e2e `components.spec.ts`, e2e `@network` `python-network.spec.ts`.
- **M1-9, analyst review:** không có lỗi bảo mật. Các lỗi tìm ra, tất cả đã sửa:
  - radio đáp án chỉ có công thức không có tên truy cập: `aria-label` tự sinh từ TeX;
  - điểm dừng Tab thừa: `overflow-y: hidden`;
  - CSS chặn render: gộp CSS component vào `customCss`;
  - lỗi Python không được đọc lên: thêm dòng sr-only báo lỗi;
  - JSON nhúng chưa escape `<`: thêm `toScriptJson`;
  - cổng e2e đổi sang 4322;
  - lỗi Tab khi radio có focus trước lúc hydrate;
  - lỗi trang chủ do việc gộp CSS gây ra (dấu ngã ba 96px bị thu còn 19px).
